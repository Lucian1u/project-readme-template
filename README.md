# Project README Template

一套给 GitHub 公开项目使用的 README 标准。它把项目用途、使用入口、真实证据、边界和验收放在固定位置，避免每次发布时重新想结构。

**[复制 README 模板](README_TEMPLATE.md)** · [查看完整标准](STANDARD.md)

**状态：** 可用。模板中的占位符需要按具体项目替换，未使用的可选章节应删除。

## 适合什么项目

- Agent Skills 与开发工具
- 本地运行或网页工具
- 有安装、演示、输出文件或验收记录的开源项目

模板不限制语言和技术栈。项目很简单时可以删掉可选章节，不需要为了套模板把 README 写长。

## 使用方法

1. 把 [`README_TEMPLATE.md`](README_TEMPLATE.md) 复制到新项目根目录
2. 改名为 `README.md`
3. 替换全部 `{{...}}` 占位符
4. 删除不适用的可选章节
5. 按 [`STANDARD.md`](STANDARD.md) 的完成标准检查后发布

## 这套标准关注什么

- 首屏能说清项目是什么，以及读者下一步该做什么
- Agent Skill 必须提供可复制的安装命令，不能只给 ZIP 或分步说明
- 功能、兼容性和项目状态都有事实依据
- 安装与验收命令已经在当前版本跑过
- 限制、未验证环境和隐私边界写在项目页上
- README 与 GitHub About、Topics、Website、License 和版本状态一致

## 文件

| 文件 | 作用 |
|---|---|
| [`README_TEMPLATE.md`](README_TEMPLATE.md) | 可以复制到新项目的 README 骨架 |
| [`STANDARD.md`](STANDARD.md) | 写作规则、GitHub 配套设置与发布前检查 |

## 隐私

模板不会要求填写本名、私人联系方式或本机路径。发布前仍要检查提交记录、截图、日志和示例内容，避免把账号凭证或私人资料一并公开。
